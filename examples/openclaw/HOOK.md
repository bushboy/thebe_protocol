# Agentic Guardian (Thebe)

**Description:** Verified Delegation Proxy for OpenClaw. Intercepts every tool call and agent bootstrap event, submits the proposed action to the Thebe Proxy for a zero-trust verdict, and blocks or flags anything that does not align with the original user intent.

- agent:bootstrap
